# Electronic Parts Inventory Manager
Exactly what is says on the tin. Just a little thing for me to manage all of my electronics goodies, because a spreadsheet just wouldnt cut it.
Run `main_cli.py`, enter `help` for the list of commands. 

Mostly a learning and practice exersize for a couple of core Python libraries I haven't touched before this (`cmd`, `argparse`, `pickle`, and abusing `__slots__` with inheritance for fun and profit). Beware ye who enter here, for there be hodge-bodge.
